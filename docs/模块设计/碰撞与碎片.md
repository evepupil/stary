## 设计

### 职责

- REBOUND C 桥负责 IAS15 推进、连续接触检测、最早接触时刻和碰前快照。
- Rust/WASM 负责 EDACM 分类、材料剥离、残体生成和守恒账本。
- TypeScript Worker 负责运行时校验、候选实例、原子切换、修订号和错误恢复。
- 主线程负责消费版本化事件和状态，不参与物理分类。
- Three.js 负责主要碎块、tracer 和视觉尘埃的显示，画质不会反向影响物理结果。

### 科学模型

主模型采用 Leinhardt-Stewart 2012 的 EDACM，Genda 2012 提供原行星 merge/hit-and-run 临界线，Marcus 2009 只用于论文覆盖范围内的类地行星外层剥离。Benz-Asphaug 1999 的速度相关强度曲线暂不进入首版。

接触输入固定为 SI 质量、半径、位置、速度、自转角动量、转动惯量因子和由外到内的材料层。内部分类保留 merge、hit-and-run、partial accretion、erosion、catastrophic disruption 和 super-catastrophic disruption；界面把它们显示为合并、擦碰、坑蚀、剥离和碎裂。

Task 1 在 `model-sources.ts` 锁定 LS2012 与 Genda2012 的 DOI、arXiv 版本、公式编号和参数。LS2012 的斜碰破坏修正在 `alpha <= 0.5` 时明确标记 `obliquityModelExtrapolated`。Genda 临界线会检查质量比、角度、速度比和总质量；原始两体的成分与自转由候选绑定入口继续核对，任何一项超出校准域都必须标记外推。

### STARY deterministic engineering v1

Task 4 把论文分类与工程重建分开版本化。分类继续使用 `stary-edacm-v1`，残体重建固定为 `stary-deterministic-v1`，WASM ABI 固定为 `1`。该版本提供可复现、可守恒、能继续模拟的候选结果，并在响应中逐项列出使用的近似。

| 结果                                         | 确定性重建规则                                                                                                                                                               |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| merge / graze-and-merge                      | 两体质量全部进入一个主要残体；位置和速度取牛顿质心；轨道角动量与原自转角动量合并为残体自转；半径按两体总体积保持平均密度；转动惯量因子按质量加权；四种材料桶先合并再归一化。 |
| hit-and-run                                  | 保留两个原参与体和原材料；把入射相对速度的向内径向分量镜像为向外分量，质心速度保持不变；机械能差进入变形耗散。精确无交互正切走同一稳定 no-op 候选。                          |
| partial accretion / erosion                  | universal law 给出最大残体质量；最大残体以外的质量聚合为一个 tracer；材料从 gas 到 iron 由外向内剥离。                                                                       |
| catastrophic / super-catastrophic disruption | 最大残体以外的质量聚合为一个 dust cohort；材料、位置和速度重建规则与其他破坏结果一致。                                                                                       |

破坏重建沿原两体连线放置最大残体和被动资产，并保持碰前质心与中心间距。切向相对速度由碰前轨道角动量反算；径向分离速度取入射径向速度、极小逃逸速度下限和可用机械能上限的确定组合，其中最多使用 `25%` 可用机械能。原两体自转角动量全部进入最大残体。机械能差只允许进入非负热、变形或破碎耗散；需要负耗散才能闭合的结果会返回 `collisionReconstructionFailed`。

首版材料规则使用四个有序绝对质量桶：`gas -> ice -> silicate -> iron`。剥离从外层开始，最大残体按保留质量重新生成材料比例，被动资产按抛射质量生成材料比例。最大残体只用总体积平均密度重建球形半径；分层密度积分、第二大残体谱、逐颗碎片速度谱和流体形变留给后续模型版本。

经典 domain 只接受 `gravitySolid` 与 `gravityFluid`，且两体半径都必须至少为 `1 km`。恒星返回 `unsupportedStellarCollision`；黑洞进入独立 `blackHoleAccretion` domain；小于 `1 km` 的强度主导天体返回 `unsupportedStrengthRegime`。

### 守恒

碰撞结果必须把全部质量分配到主要残体、tracer 或有物理质量的 dust cohort。GPU visual debris 的质量固定为 `0`，只引用 cohort 做画面采样。线动量、轨道加自转角动量、机械能和耗散项进入独立账本。

| 项目     | 相对误差门槛 |
| -------- | ------------ |
| 质量     | `1e-12`      |
| 线动量   | `1e-10`      |
| 角动量   | `1e-8`       |
| 能量账本 | `1e-6`       |

守恒分为 `event-total` 和 `active-REBOUND`。前者在接触时刻计算主要天体、tracer、dust cohort、自束缚能和 subgrid 机械能的事件闭合；后者只衡量主要天体在碰撞之间的 IAS15 数值漂移。被动碎片省略的反作用冲量、角冲量和功单独累计。

碰撞机械能损失必须进入非负的热、变形、破碎或辐射项。需要负耗散才能闭合的候选会被拒绝。系统诊断分开显示真实碰撞耗散、积分数值漂移、被动模型近似和未展开机械能。

### 连续接触

C 桥在一次原生 integrate 的 heartbeat 中观察 IAS15 接受步，步首复制完整 simulation。每段先用真实步首距离的一半建立 separation enclosure；只有相对运动界证明该距离下界覆盖整段，才使用步首、步尾弦与 `A_rel_bound h^2/8` 曲率上界排除接触。无法证明时，所有采样都从同一个不可变 checkpoint 直达目标时刻并左优先细分。

穿透先找到物理表面间隙的正负括号，再二分最早零点；正切先二分径向速度零点，再核对距离容差。同刻集合保留根时间落在时间容差内的 pair，随后补收最早接触快照中正在接近或相切的 pair。粒子下标进入 TypeScript 后按 UTF-8 稳定 ID 规范化和排序。

距离容差同时考虑接触半径、世界坐标 ULP 和 `256 * DBL_EPSILON * worldScale` 固定回放位置预算。深度、节点、replay 或 pair 容量用尽会明确失败并回滚当前接受步。C 返回最早事件簇内的全部 pair；成功产生的临时 copy 只能经过统一释放或收养 helper，所有可恢复返回路径都要求计数归零。底层 WASM OOM abort 属于进程级失败，不承诺在进程终止后继续恢复。

初始重叠且正在接近或静止会立即产生事件。正在分离的重叠体只有在 enclosure 与径向变化上界证明区间安全时才继续；强引力把它拉回后会重新产生事件。`clearPendingContact()` 会确认当前 pair；正切 pair 只有在弦曲率下界证明未重新穿透时才暂时抑制。解析失败走独立 discard，不会把未解决事件标成已确认。连续接触导出只接受 IAS15，WHFast 会明确返回不支持。

### 事务与错误

正式模拟使用 `advanceUntilEvent`。没有接触时推进到目标时间；有接触时停在最早事件。互不共享天体的二体接触从同一碰前快照计算并整批提交；共享天体的三体或更多接触超出首版模型范围，会保留接触态并安全暂停。

Rust 结果通过 schema、容量和守恒检查后，Worker 才创建候选 REBOUND 并原子切换。失败会保留接触时刻的旧实例，销毁候选资源，保持修订号并安全暂停。成功事件通过单个 `collisionBatchResolved` 消息携带同刻事件、账本、新状态和修订号，旧 state 不能覆盖结果。

所有 Worker 成功响应使用 `replyToSequence` 关联原命令，后台推送使用 `null`。运行中的首次不可逆碰撞默认暂停。单步遇到接触时返回包含原目标和实际接触时间的提前暂停结果，因此 controller 不会继续等待原目标。

### 碎片层级

- 每次最多 64 个主要残体，总主要天体不超过 512；它们继续参与完整多体引力。
- tracer 携带代表质量，只受主要天体引力。
- dust cohort 携带聚合质量、位置、速度、材料和 subgrid 机械能，只受主要天体引力。
- tracer 与 dust cohort 共用 10,000 个被动物理资产名额；两类各自也不能超过该上限。
- visual debris 目标上限为 50,000，质量固定为 `0`，只负责画面。
- 固定事件 ID、父体排序和碎片序号生成确定性 seed。
- 容量不足时，质量较小的结果进入 tracer 或 dust cohort，质量不能消失。

### 批次、容量与确定性

- 单个请求携带 `1..256` 个事件。事件 ID 必须唯一，同一批次禁止共享参与体；Worker 在构造请求前会再次按接触图拒绝多体连通分量。
- Rust 在求解前按 UTF-8 `eventId` 严格递增排序。目标体按质量、半径、UTF-8 ID 依次定序，父体输入交换不会改变稳定 ID。
- 碎片 seed 对编码版本、模型版本、事件 ID、规范父体 ID、资产种类和序号分别加 32 位大端长度前缀，再计算 FNV-1a 64。输出 ID 不能与同批输出或其他事件参与体冲突；hit-and-run 只允许保留本事件原 ID。
- `majorRemnantSlots` 与 `passiveAssetSlots` 统计整批新结果。参与体旧槽位由调用方在提交前统一扣除或归还；Rust 按事件顺序递减剩余容量，任一事件超限会让整个批次返回单个 `collisionCapacityExceeded`，不会返回部分成功。
- 经典成功结果的账本范围固定为 `participantLocalEventTotal`，只包含本次二体参与者和本次生成资产。Worker 合并回完整宇宙后重算全局状态与 active-REBOUND 诊断。
- Rust 使用 `serde_json` 的 `float_roundtrip`，锁住 JSON 到 `f64` 的往返。跨语言测试要求对象结构、枚举、ID 和零值精确一致；少数 `hypot/cbrt/pow` 末位差异限制在 `32 * Number.EPSILON` 相对误差内，并锁定允许出现差异的字段路径。

黑洞使用独立 `blackHoleAccretion` domain，至少一个参与体必须是黑洞，恒星与黑洞组合仍会安全拒绝。残体质量、位置和速度使用牛顿质心，半径取 Schwarzschild 半径 `2GM/c^2`，轨道角动量与原自转全部进入残体自转。非黑洞参与体的四种材料质量进入 `accretedMaterialMassesKg`；质心系相对动能全部记为 `radiationJoules`。该账本只校验质量、线动量、角动量和质心系相对动能，不包含引力波质量损失、Kerr 自旋上限或广义相对论并合。

Rust/WASM ABI 1 只导出以下八个函数：

```text
stary_collision_abi_version
stary_collision_create
stary_collision_alloc
stary_collision_buffer_ptr
stary_collision_buffer_len
stary_collision_resolve
stary_collision_destroy
stary_collision_live_count
```

一次调用的所有权顺序固定为 `create -> alloc -> write -> resolve -> read -> destroy`。上下文状态依次为 fresh、request、resolving、response；第二次 alloc、第二次 resolve、重复 destroy 和 stale token 都返回状态 `1`，不会触碰新上下文。`create` 使用不复用的单调 32 位 token；`live_count` 用于泄漏验收。请求上限为 `1 MiB`，响应上限为 `16 MiB`；超限返回状态 `2`，请求缓冲分配失败返回状态 `3`，成功为 `0`。

请求和响应缓冲区都归上下文所有。`resolve` 可以增长 WASM memory，因此 TypeScript 在每次读取 pointer 和 length 后重新创建 view，禁止持有旧 `ArrayBuffer`。适配器在 `finally` 中销毁上下文，resolve trap 也会清理。模块没有 host import、`wasm-bindgen`、table 或 exception tag；release 使用 `panic=abort` 和整数溢出检查。不可恢复 OOM 仍属于进程级终止边界。

固定构建使用 Rust/Cargo `1.96.0`、`wasm32-unknown-unknown` 和 `linux/amd64` 的 `rust:1.96.0-bookworm@sha256:c993d32d95cc146bd12c84d66f0b924a6a96f3988325f39c144f2f9893dea120`。产物锁覆盖 golden fixture、Cargo 清单和锁、工具链、构建/验证脚本及全部 Rust 源码。`dist/` 只允许 `stary_collision.wasm`：当前固定大小 `361,709 bytes`，SHA-256 为 `C2D01ACB56BB528625FB90D0D651000CB30A1E59FCBE6931B14076BB735CD5D3`。

### Task 5 当前实现

- `physics.worker.ts` 把固定 Collision WASM 地址传入 runtime，内核在 Worker 初始化期间加载一次。初始化任一步失败都会销毁已创建的 REBOUND 实例并关闭 Worker。
- `PhysicsSimulation` 提供 `advanceUntilEvent` 和接触清理边界。单步命令与连续运行共用同一推进路径；调度片段与命令进入串行队列，候选创建期间不会并发改写状态。
- `collision-transaction.ts` 在调用 WASM 前拒绝共享天体的同刻接触，构造稳定事件 ID 与容量，对经典结果使用原始二体重新计算可信账本，黑洞使用独立吞噬账本。
- 碰撞结果合并未参与天体、原有被动资产与新碎片，然后以原惯性参考系创建候选 REBOUND。候选时间、天体集合、质量、半径、位置和速度逐项一致后才进入正式状态。
- 候选失败会销毁候选实例，保留旧 REBOUND 的挂起接触、接触时刻状态、修订号与批次号。成功后一次替换实例和完整 `PhysicsState`，修订号与批次号各递增一次，随后销毁旧接触实例。
- `passive-assets.ts` 用 velocity Verlet 分步推进 tracer 与 dust cohort，主要天体在物理片段内线性插值。每步最长 `3600 s`，单次最多 `4096` 步；完成后重算被动资产诊断并累计省略反作用。
- 运行和单步遇到成功碰撞都会发送一个 `collisionBatchResolved` 并暂停。后台调度异常会转为 `internalError` 并安全暂停，不会留下假运行状态。

以上路径均相对 `src/features/observatory/`。关键决策：

- 协议 v3 保持不变。接触速度按 LS2012 定义 `Q_R = mu v^2 / (2 M)` 用碰前参与体快照精确反推，互逃逸速度用 `2GM/(R1+R2)` 重算；参与体快照在批次落地时从上一帧状态截取。
- visual debris 没有协议表示，质量恒为 `0`，只按 dust cohort 的确定性种子采样；同一 cohort 在任何后端、任何帧得到相同粒子云。
- 粒子预算：WebGPU `50,000`、WebGL2 `20,000`，单 cohort 上限 `2,048`；降低预算只减少视觉粒子，tracer、dust cohort 与主要碎块两个后端完全一致。
- 主要碎块不走专用链路：`major-*` id 出现在 `majorBodies` 后由既有的目录、外观、轨道与选择 diff 直接处理，目录用"碰撞产物"分组命名。

## 已知边界

- EDACM 是分析标度模型，不做逐单元流体仿真。
- 气态巨行星使用无强度流体近似。
- 恒星、小于 `1 km` 的强度区和完整相对论黑洞并合不在首版支持范围。
- passive tracer 和 dust cohort 不产生主动引力；省略反作用会明确进入模型近似诊断。visual debris 没有物理质量。
- 被动资产诊断的机械能包含主要天体与被动资产的势能。碰撞原子合并和天体替换都会基于完整宇宙刷新 `totalMechanicalEnergyJoules`。
- M4 才实现碰撞事件的快照、撤销和确定性历史回放。
