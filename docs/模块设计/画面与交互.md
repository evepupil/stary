# 画面与交互

## 当前状态

M0 Task 5 已完成双天体观测台。页面读取正式物理 Worker 的太阳地球快照，使用 Three.js 绘制全屏场景，并提供相机、天体选择、暂停、单步、倍率、守恒量和手机抽屉。

## 设计

### 职责

本模块负责把 SI 物理状态变成可观察的画面和界面。它只读取 `BodyState` 与 `PhysicsDiagnostics`，不会修改质量、半径、位置、速度或积分器设置。

职责分为三块：

- `simulation/` 管 Worker 生命周期、React 状态、命令队列和显示换算。
- `rendering/` 管 Three.js 后端、坐标缩放、轨道、相机、选择和资源释放。
- `components/` 管顶栏、天体目录、数据面板和时间控制。

### 视觉与布局

画面方向是科学观测台。背景固定为 `#030506`，面板使用半透明深色表面，正常状态色为 `#4cc9b0`，圆角不超过 `6px`。画布铺满视口，桌面端左右面板保持窄而克制，底部只放时间控制。

手机端隐藏左右面板原位内容，通过“天体”和“数据”两个按钮打开底部抽屉。抽屉底边位于切换按钮上方，时间控制固定在最底部，三者都叠加 `safe-area-inset-bottom`。关闭的抽屉使用 `visibility`、`opacity` 和指针状态隐藏，避免视口外位移扩大页面滚动区域。

## 实现细节

### 模拟状态 Hook

`useUniverseSimulation` 创建 `PhysicsWorkerController`，按以下顺序启动：

1. 用真实太阳地球 SI 状态初始化。
2. 设置默认倍率 `86400x`。
3. 启动连续模拟。

Hook 暴露运行阶段、运行状态、天体、诊断量、模拟秒数、当前倍率、错误和命令等待状态。启动、暂停、单步、倍率和重试命令进入同一 Promise 队列，界面不会并发发送互相冲突的命令。拒绝结果会转换成可见错误，避免未处理 Promise。

`PhysicsWorkerController` 还提供致命故障订阅。原生 `error`、`messageerror`、协议损坏、超时或不可恢复错误会先通知 Hook，再关闭 Worker。Hook 收到通知后清空 controller 引用和等待命令，把阶段改成错误、运行状态改成暂停，界面不会继续显示“模拟运行中”。

Worker 可以高频发送 `state`。Hook 只保留最新快照，并通过 `requestAnimationFrame` 每帧最多更新 React 一次。第一个诊断快照固定为守恒基线，后续界面据此计算能量、线动量和角动量的相对漂移。

### 坐标与真实尺寸

物理位置保持米。`computeMetersToSceneUnit` 根据当前系统最远天体计算统一比例，把天文距离映射到约 `10` 个场景单位。这个比例只存在于渲染模块。

天体 sphere 的缩放严格使用 `radiusMeters * metersToSceneUnit`。地球在一 AU 视角下通常小于一个屏幕像素，因此场景额外绘制始终朝向相机的定位环。定位环按相机距离和视口高度维持最小 `9px`，选中时为 `12px`。每个定位环还带有不写入颜色的 `20px` 实心命中圆盘，点击中心和手机触控都能稳定选择；真实 sphere 继续保持物理尺寸。

### 轨道与场景

场景从当前相对位置和速度计算瞬时密切轨道。大白话说，这条线表示天体按照当前状态继续运动时对应的椭圆轨道。采样使用真实引力常数、总质量、角动量和偏心率，双曲线或无有效轨道时不画误导性闭合线。

太阳使用自发光基础材质并提供点光源，地球使用受光材质。固定种子的星空保证每次启动一致。轨道、定位环、星空和天体都在同一三维场景中，OrbitControls 提供阻尼环绕和滚轮缩放。

### 相机适配

相机首次布局时根据垂直视场角和宽高比计算距离，保证 `±10` 场景单位进入视野。`390×844` 窄屏会自动拉远，太阳、地球和轨道可以同时出现。用户开始拖动后，窗口变化只更新投影和尺寸，不再强行覆盖用户相机位置。

### 渲染后端与清理

观测台先请求 WebGPU 适配器并初始化 `WebGPURenderer`。适配器、模块或初始化失败时，代码创建明确绑定 `webgl2` 上下文的 `WebGLRenderer`。两套模块与观测场景都通过动态导入进入独立生产分块。

组件卸载时会取消动画帧、断开 ResizeObserver、释放 OrbitControls、移除指针监听、销毁 geometry、material、light 和 renderer，并在 WebGL2 下主动释放上下文。场景构造或首次状态更新中途失败也执行同级回滚，重试时不会残留旧画布或监听器。

### 控制与错误

底部时间条提供开始或暂停、单步一小时和四档倍率。运行时单步按钮禁用，命令执行期间所有冲突控制禁用。Worker 或渲染错误会显示“模拟已安全暂停”，重试会同时重建 Worker 和画布。

## 验证

- Vitest 覆盖状态映射、时间和单位格式化、守恒漂移、坐标比例、真实半径、定位环、轨道采样、相机桌面与手机适配。
- Playwright 覆盖生产画布非背景像素和青绿色轨道像素、WebGPU 可用时的真实后端、透明点击区选择地球、暂停、精确单步 `3600` 秒、倍率、恢复运行、手机抽屉零滚动，以及屏蔽 WebGPU 后的真实 WebGL2 回退。
- 应用内浏览器在桌面 `1280×720` 和手机 `390×844` 验证 WebGPU 画面、相机环绕与缩放、面板尺寸、手机抽屉和控制台。
