# 画面与交互

## 当前状态

M2 已完成真实画面验收。聚焦近景会把目标天体作为移动渲染原点，相机平滑跨越系统、轨道区和表面尺度；孤立黑洞在桌面 WebGPU 与手机 WebGL2 中都拥有可辨识暗核和光子环。正式性能矩阵、资源循环、加载失败恢复和三尺寸布局截图均已进入持续门禁。

## 设计

### 职责

本模块负责把 SI 物理状态变成可观察的画面和界面。它只读取 `BodyState` 与 `PhysicsDiagnostics`，不会修改质量、半径、位置、速度或积分器设置。

职责分为三块：

- `simulation/` 管 Worker 生命周期、React 状态、命令队列和显示换算。
- `rendering/` 管 Three.js 后端、坐标缩放、轨道、相机、选择和资源释放。
- `components/` 管顶栏、天体目录、数据面板和时间控制。

### 视觉与布局

画面方向是科学观测台。背景固定为 `#030506`，面板使用半透明深色表面，正常状态色为 `#4cc9b0`，圆角不超过 `6px`。画布铺满视口，桌面端左右面板保持窄而克制，底部只放时间控制。

手机端隐藏左右面板原位内容，通过“天体”和“数据”两个按钮打开底部抽屉。抽屉底边位于切换按钮上方，时间控制固定在最底部，三者都叠加 `safe-area-inset-bottom`。关闭的抽屉使用 `visibility`、`opacity` 和指针状态隐藏，避免视口外位移扩大页面滚动区域。

### 真实画面配置

`appearance/` 只输出纯数据外观，不创建 Three.js 对象。恒星、岩石、气态巨行星、冰巨行星、无气层和黑洞分别拥有稳定表面类别、颜色、粗糙度、温度和可选灯光参数。主序星光度使用分段质量关系估算，再结合半径得到有效温度；渲染值设有明确上下限，防止极端编辑参数产生无穷亮度或颜色。

最多四颗质量最大的恒星提供场景灯光，同质量按 ID 稳定排序。其余恒星继续显示自发光表面与光晕，不创建额外 PointLight。点光源使用平方距离衰减，并以 30 AU 映射到 10 个场景单位作为显示基准；场景重新标定时强度按比例平方补偿，避免远处新增天体改变原有恒星与行星的照度。极端缩放产生的显示强度会夹紧到有限上限，优先保证渲染器稳定。行星、卫星、黑洞和未知天体不会误发光。

`visuals/` 拥有正式天体的 surface、star halo、marker ring、planetary ring 和可选 light。恒星表面使用稳定种子生成细微温度单元，光晕使用小型径向 DataTexture。固定太阳系天体可以把本地颜色图绑定到原有材质，动态创建天体继续使用程序化表面。LOD 变化只替换并释放 geometry，纹理租约保持不变；单体删除和场景销毁会释放完整 geometry、material、texture 与 light。

`assets/` 保存严格资产清单、天体映射、浏览器加载器和场景级纹理缓存。加载器检查 HTTP 状态和图片 MIME，再创建 ImageBitmap 与 Three Texture。缓存共享同一资产的待决请求，用引用计数决定释放时间；最后一个消费者离开时同时释放 GPU 纹理和解码位图。失败会保留原有程序化外观，不会让天体从场景消失。

`appearance/body-environment.ts` 保存地球、金星和火星的大气与云层参数。`visuals/body-environment.ts` 创建双层大气、地球云层和云影，按天体快照模拟时间设置绝对云相位，并按投影大小和恒星方向控制效果。`lighting/stellar-occlusion.ts` 使用 SI 位置与半径计算恒星圆盘可见比例；结果进入地表明暗、大气、云影和曝光。完整职责与近似边界记录在 `docs/模块设计/大气云层与光照.md`。

`appearance/black-hole-appearance.ts` 保存黑洞的物理比例，`visuals/black-hole.ts` 拥有暗核、光子环和可选 WebGPU 光晕资源。当前物理状态没有吸积物质字段，因此不会凭外观类别生成吸积盘。

## 实现细节

### 模拟状态 Hook

`useUniverseSimulation` 创建 `PhysicsWorkerController`，按以下顺序启动：

1. 用 JPL J2000 太阳系 10 体 SI 状态初始化。
2. 设置默认倍率 `86400x`。
3. 启动连续模拟。

Hook 暴露运行阶段、运行状态、天体、诊断量、显示模拟秒数、天体快照模拟秒数、当前倍率、错误和命令等待状态。`bodySnapshotSimulationTimeSeconds` 只随天体快照更新，`status` 或 `error` 只会改变显示时间，后续创建草稿必须使用前者。启动、暂停、单步、倍率和重试命令进入同一 Promise 队列，界面不会并发发送互相冲突的命令。拒绝结果会转换成可见错误，避免未处理 Promise。

`PhysicsWorkerController` 还提供致命故障订阅。原生 `error`、`messageerror`、协议损坏、超时或不可恢复错误会先通知 Hook，再关闭 Worker。Hook 收到通知后清空 controller 引用和等待命令，把阶段改成错误、运行状态改成暂停，界面不会继续显示“模拟运行中”。

Worker 可以高频发送 `state`。独立消息调度器只保留最新快照，并通过 `requestAnimationFrame` 每帧最多更新 React 一次；销毁时会取消待决帧并忽略残留回调。第一个诊断快照固定为守恒基线，后续界面据此计算能量和角动量的相对漂移。质心系初始线动量接近零，比例容易放大浮点消差噪声，因此线动量使用相对基线的绝对残差。

Hook 还暴露原子 `replaceBodies` 命令，供创建与编辑界面复用。调用方必须把草稿创建时的 `expectedBodyRevision` 和 `bodySnapshotSimulationTimeSeconds` 一并提交。创建、编辑或删除开始时先暂停，再从同一份天体快照建立操作基线。成功确认会同步替换天体和诊断、把运行态保持为暂停，并重建守恒基线。消息调度器会在确认到达时清除替换前已缓存的旧状态，状态模型再按修订号和应用序号做第二层保护。

参数编辑和删除使用独立 Hook。修订或快照时间冲突会停在可见的“正式状态已变化”阶段，只有用户点击重新同步才会读取最新快照。重同步保留当前输入，重新计算候选状态和短期预览；取消操作会按进入工具前的状态决定是否恢复运行。

状态模型分开保存两个序号。`latestAppliedSequence` 记录最后应用的天体快照或替换确认，用于拒绝延迟消息；`latestStateSequence` 只在真正的 `state` 到达时更新，并通过观测台根节点的 `data-worker-state-sequence` 提供只读诊断。性能探针用后者的相邻差值测量 Worker 状态推进频率，替换确认不会抬高该指标。

### 坐标与真实尺寸

物理位置保持米。`computeMetersToSceneUnit` 根据当前系统最远天体计算统一比例，把海王星尺度映射到约 `10` 个场景单位。这个比例只存在于渲染模块。

天体 sphere 的缩放严格使用 `radiusMeters * metersToSceneUnit`。行星在全景下一般小于一个屏幕像素，因此场景额外绘制始终朝向相机的定位环。定位环按相机距离和视口高度维持最小 `9px`，选中时为 `12px`；真实 sphere 继续保持物理尺寸。

M2 增加 `system`、`orbit`、`surface` 三档观察尺度和 `low`、`medium`、`high` 三档球体 LOD。层级根据真实球体的投影像素半径选择，并用不同的进入/退出阈值防止临界位置抖动。WebGL2 保留相同层级语义，最高球体分段低于 WebGPU。聚焦天体已经清楚可见时会隐藏定位环，避免标记遮住表面。

固定太阳系天体在成为焦点或投影半径进入 medium LOD 后启动纹理加载。一次加载成功后，后续 LOD 切换只更换球体几何，材质和纹理租约继续复用。未访问的远景天体不会提前解码全部贴图。

场景比例继续使用一套物理范围。物理范围相对上次基线扩大超过 5% 或缩小超过 50% 时重新标定，因此同 ID 天体被大幅移动或修改半径后不会长期沿用旧比例；小幅轨道运动保持稳定，避免画面呼吸。

全景使用 SI 零点。聚焦时使用目标天体的 SI 位置作为渲染原点，天体、轨道、创建草稿和预览轨迹在 CPU 端先减原点，再写入 Three.js 的浮点坐标。焦点天体移动时只更新原点对应的世界位置，相机和过渡保持本地坐标；切换焦点和返回全景才执行一次世界构图重投影。

全景中的内行星定位点可能重叠。场景按选中天体、太阳和目录顺序保留优先项，中心小于 `18px` 的低优先级环会隐藏。点击使用可见定位点的实时屏幕坐标，在 `20px` 半径内选择最近天体，不再依赖透明几何的三维深度顺序。

避让只隐藏画布定位环。分组目录继续列出当前模拟中的全部天体，用户可以从目录查看和聚焦任何被隐藏的天体。

### 轨道与场景

场景从当前相对位置和速度计算瞬时密切轨道。大白话说，这条线表示天体按照当前状态继续运动时对应的椭圆轨道。目录声明轨道父级，八大行星围绕太阳，月球围绕地球。声明了具体父体但该父体已经删除时，场景按当前位置的引力优势选择剩余主导天体；目录明确声明 `orbitParentId=null` 时继续保持无父体。采样使用真实引力常数、父子总质量、角动量和偏心率，双曲线或无有效轨道时不画误导性闭合线。

渲染角色由天体目录元数据决定。太阳和动态创建的恒星使用自发光基础材质，质量最大的四颗恒星提供点光源，同质量按稳定 ID 排序；其余恒星保留自发光表面和光晕。黑洞、行星、卫星和未知天体不会因为质量较大而成为光源。固定种子的星空保证每次启动一致。星空跟随相机并按当前 far 调整尺寸，黑洞近景缩短裁剪范围后仍有背景参照。轨道、定位环、星空和天体都在同一三维场景中。

### 观测数据

质量、平均半径和质心距离直接从 SI 状态换算显示。速度按目录中的轨道父级计算：月球显示相对地球速度，八大行星显示相对太阳速度，没有父级的天体显示质心系速度。相对速度使用父子速度向量之差，避免把月球绕太阳系质心约 `30 km/s` 的运动误写成月球绕地球速度。

### 相机适配

首屏使用全景模式，相机根据垂直视场角和宽高比计算距离，保证 `±10` 场景单位进入视野。选择固定太阳系天体后进入真实半径近景，普通天体使用 `2.1R` 留白，土星按 `2.27R` 外环再次扩展构图；动态普通天体继续用轨道父级与选中天体的包围范围计算镜头，黑洞按可观察阴影外轮廓进入近景。焦点切换保留当前方向，控制中心线性移动，距离按对数插值并使用缓入缓出。顶部全景图标用同样过渡恢复完整太阳系视角。

`system`、`orbit`、`surface` 继续用于 LOD、诊断和裁剪范围。滚轮、旋转与阻尼速度按聚焦天体的投影半径连续插值，跨层级没有硬跳。near 对三档统一使用相机到可观察外轮廓的安全空隙，最小距离停在轮廓之外；far 随系统、轨道区和近景范围分别调整。

React 保存受控的聚焦天体 ID。渲染器和场景分块尚在异步加载时，用户选择的焦点会先被记住，场景创建完成后重放当前聚焦意图。新建天体的焦点早于 bodies 到达场景时，只保存这一次失败意图，下一批 bodies 更新后重试并清除。普通 Worker 快照只更新场景和跟随位置，不会再次调用聚焦，因此用户滚轮和旋转不会被重置。窗口尺寸变化时，用户尚未调整相机则重新计算当前全景或聚焦镜头；用户已经旋转或缩放后只更新投影和渲染尺寸，保留已有构图。

进入创造模式时，场景保存相机位置、四元数、控制中心、裁剪范围、缩放边界和当时的场景比例，随后切到正对 `z=0` 创建平面的俯视镜头。创造期间停止 OrbitControls 阻尼更新，尺寸变化会重新计算俯视范围。若新建天体改变系统范围，退出时按新旧场景比例换算保存的聚焦相机，再恢复导航裁剪范围；原来的方向和画面大小不会丢失。

编辑使用同一套草稿覆盖层绘制候选天体和预览轨迹，但相机模式为 `preserve`，不会切到创建俯视镜头，也不会关闭 OrbitControls。编辑覆盖层关闭放置手势，画布只展示候选状态；确认编辑后继续聚焦原天体，确认删除后切换到回退天体或全景。

### 渲染后端与清理

观测台先请求 WebGPU 适配器并初始化 `WebGPURenderer`。适配器、模块或初始化失败时，代码创建明确绑定 `webgl2` 上下文的 `WebGLRenderer`。两套模块与观测场景都通过动态导入进入独立生产分块。

组件卸载时会取消动画帧、断开 ResizeObserver、释放 OrbitControls、移除指针监听、销毁 geometry、material、纹理租约、ImageBitmap、light 和 renderer，并在 WebGL2 下主动释放上下文。场景构造或首次状态更新中途失败也执行同级回滚，重试时不会残留旧画布或监听器。加载中的天体被删除时会取消自己的等待；同一共享请求的其他消费者继续等待。

两条后端当前只使用共同支持的内置材质、DataTexture 和 Sprite。大气使用透明背面双层球壳，云影与环影使用贴近表面的透明球面。黑洞使用共享的 256×256 程序化 DataTexture 表现暗核与光子环，WebGPU 额外叠加冷色透镜光晕，WebGL2 保留单 Sprite 回退；Sprite 参与深度测试并在交互标记之前绘制。完整 Rayleigh/Mie 散射、自定义 TSL/GLSL 和全屏背景扭曲需要独立兼容性验证后再进入正式场景。ACES 色调映射在全景使用 `1.1`，近景根据恒星、受光相位和遮挡比例平滑适应。

`?visualDiagnostics=1` 每 100 毫秒最多更新一次实际场景帧数、尺度档、LOD 数量、相机距离与裁剪面、过渡、移动原点、表面类别、曝光、天体投影、环境、环、黑洞组成和资源数量。资源快照按对象身份去重统计场景中的 geometry、material、texture、light 和 object，另外记录纹理缓存、黑洞共享纹理池、Scene 与 Renderer 的创建、释放和活动数量。当前画面没有项目级 render target，对应计数固定为零。浏览器验收按投影区域采样正式资源，诊断只在显式查询参数下开启。

场景动态分块加载失败时，模块加载器从同源错误中提取实际哈希分块 URL，并在下一次视口重建时增加递增查询参数。这样可以绕过浏览器对失败 ESM 请求的缓存，继续复用已经成功加载的模块 Promise。失败尝试创建的 Renderer 会先释放，恢复后页面只保留一个 Scene、一个 Renderer 和一个 canvas。

### 控制与错误

底部时间条提供开始或暂停、单步一小时和四档倍率。运行时单步按钮禁用，命令执行期间所有冲突控制禁用。Worker 或渲染错误会显示“模拟已安全暂停”，重试会同时重建 Worker 和画布。

顶部中央增加观察、创造和实验分段开关，实验入口暂时禁用。创造模式使用固定俯视相机和 pointer capture，把按下点映射到 `z=0` 轨道平面，拖动差值转换成初速度。草稿球、速度箭头和预览轨迹使用独立资源，退出模式或更新草稿时立即释放，不进入正式天体定位点和选择列表。

目录和详情面板提供编辑、删除入口。创建活动时这些入口禁用；编辑或删除活动时创造开关禁用，右侧区域只显示当前操作面板。参数变化经过 250ms 防抖后更新候选球和轨迹，删除确认阶段不生成草稿画面。删除确认把背景设为不可交互，键盘焦点只在确认框内循环；关闭并完成物理命令后，焦点回到当前详情的删除按钮。

桌面端创建面板替换右侧数据面板。手机端创建面板固定在底部，隐藏原目录、数据切换和时间控制，保留上半屏画布。

## 验证

- Vitest 覆盖状态映射、时间和单位格式化、父级相对速度、守恒漂移与线动量绝对残差、坐标比例、真实半径、定位环、轨道采样、相机桌面与手机适配。
- Playwright 覆盖 10 体目录、生产画布非背景像素和选中轨道像素、WebGPU 可用时的真实后端、实时定位环像素与点击外行星、相机诊断、海王星聚焦、返回全景、场景分块延迟时的焦点重放、暂停、精确单步 `3600` 秒、倍率、恢复运行、手机滚动目录、创建与编辑、删除确认焦点循环、手机编辑面板、真实 WebGL2 回退和 WebGL2 创建、编辑与删除。
