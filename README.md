# STARY

STARY 是一个运行在浏览器中的恒星系统级宇宙沙盒。用户可以观察真实尺度的多天体运动，创建和编辑天体，控制模拟时间，并逐步开展碰撞、回放和分享实验。

项目将物理计算与画面表现分开处理。质量、半径、位置和速度使用真实单位参与计算；轨道线、定位环和后续视觉特效只帮助观察，不会修改物理结果。

## 功能清单

### 已完成

- 使用固定版本的 REBOUND 5.0.1 WASM 和 IAS15 积分器推进多体引力模拟。
- 物理计算运行在独立 Web Worker 中，界面与计算互不阻塞。
- 使用 SI 单位保存质量、半径、位置和速度，并显示能量与角动量漂移。
- 内置 JPL J2000 太阳系 10 体场景：太阳、八大行星和月球。
- 提供天体目录、父级轨道、全景、选择、聚焦跟随和拥挤定位点避让。
- 提供暂停、单步、四档时间倍率和运行错误恢复。
- 支持创建恒星、岩石行星、气态行星、卫星、黑洞和小行星群。
- 支持通过画布放置天体、拖动设置初速度，并预览未来轨迹、碰撞风险和逃逸风险。
- 支持编辑天体质量、半径、位置和速度，以及安全删除天体。
- 画面优先使用 WebGPU，初始化失败时自动回退到 WebGL2。
- 支持桌面观测面板和手机底部抽屉，关键流程已有 Playwright 浏览器验收。

### 进行中

- 收集 M1 多天体场景的性能数据和生产包体变化。
- 补齐 M1 测试矩阵、已知限制和阶段验收文档。

### 尚未实现

- NASA 行星表面素材、程序化行星纹理、云层、大气散射和高动态范围曝光。
- 日食、月食、行星环阴影、多恒星真实照明和黑洞光线弯曲。
- 天体碰撞、撞击坑、物质喷射、碎裂、合并和大规模视觉碎屑。
- 历史快照、倒退、回放、实验分支、自动保存和文件导入导出。
- 面向不同设备的自动画质分档，以及 512 个主要天体和 50,000 个视觉碎屑的目标规模验收。

## 技术栈

- React 19、TypeScript 6、Vite 8
- Three.js、WebGPU、WebGL2
- REBOUND 5.0.1、WebAssembly、Web Worker
- Zod、Vitest、Playwright、ESLint、Prettier

## 本地运行

环境要求：Node.js `22.14.0`、pnpm `10.21.0`。

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

常用检查命令：

```powershell
pnpm format:check
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm check
```

首次运行浏览器验收前安装 Chrome：

```powershell
pnpm test:e2e:install
```
